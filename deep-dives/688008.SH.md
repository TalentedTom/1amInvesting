## 1. Supercycle, supply chain and durable advantage

Montage sells the interfaces that allow higher-speed memory and data-center interconnects to operate reliably. JEDEC participation, analog design and multi-year CPU/memory qualifications create a durable barrier. Three principal DDR4/DDR5 RCD suppliers remain, so this is a concentrated global market rather than sole-source supply. Its products serve both x86 and Arm platforms. More memory channels and new interfaces expand content, but MRDIMM can replace some conventional RCD demand.

CPU platform design → memory-module specifications → qualified RCD/MRCD/MDB/CKD and companion chips → server modules. PCIe/CXL products connect additional data paths. DRAM makers and module vendors pay for interface content; Montage does not capture the value of all memory capacity. Renesas and Rambus are relevant alternatives. Samsung and SK Hynix next-generation CXL modules provide design-in evidence, not disclosed order values.
