## Supercycle: DB (memory shortage) + endpoint AI + China storage localization

## Core Thesis: The Independent-Memory Platform at the Cycle's Sweet Spot — Trying to Become an Architecture

World's second-largest independent semiconductor memory company and China's largest (HKEX application, 2025 storage-product revenue; ~1.2% global storage share). Buys wafers, designs controllers/firmware, packages/tests, sells branded storage (Lexar, FORESEE, Zilia) across embedded, SSD, mobile, DRAM modules, enterprise. **Not MU/Samsung/SKH — owns no wafer capacity**; prints huge profits in a tight cycle while remaining downstream of the IDMs.

**The real bull case is the architecture pivot, not the price cycle:** HLC technology lets SSD/UFS take over warm/cold data-cache work normally handled by DRAM — NAND as DRAM extension at the endpoint. Company claims: AMD platform testing showed SPU + iSA increased AI-PC model-size capability ~3.2x and memory utilization ~200%; Unisoc testing showed 4GB DDR + HLC approaching 6-8GB DDR response times. **Live breadcrumb (H1 preannouncement): joint tuning with AMD completed; SSD storage agent + HLC reduced endpoint-AI DRAM usage ~40%.** If HLC/SPU becomes a durable endpoint-AI memory architecture rather than a cycle windfall, the name re-classes. Cross-links to the book's memory-efficiency watch (HBM→NAND tier rotation) — the endpoint twin of SNDK's KV-cache vector.
